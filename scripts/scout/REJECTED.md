# Rejected checks

- Infer Zoo stage or current spec from newest file timestamp: recency cannot
  establish ownership or an approval boundary.
- Check whether agents used a particular app or command: repo files cannot prove
  external session behavior. Document requirements; validate real integrations.
- Require a Go module or Xcode project: the first product stage is not selected.
- Check credentials with broad keyword matches: examples and instructions would
  trigger false positives. Add precise checks only for demonstrated patterns.
